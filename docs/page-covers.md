# 网页封面与详情布局

设置中的「网页封面」在预览图与首屏截图之间切换，立即生效并本地保存。详情右上角复用首页的照片墙 / 列表切换；布局也会记住。界面没有新增采集进度、来源角标或操作面板。

## 图片获取

- 预览图依次考虑 Open Graph、Twitter 分享图、JSON-LD 图片与正文大图。支持相对路径、懒加载和 srcset；过滤小图、图标、明显头像与追踪像素。依次验证候选图能否下载、解码，不接受 SVG 或可执行 URL。当前不使用 AI 选图，不增加模型调用或费用。
- 首屏截图实际渲染 1280 × 800 的桌面视口，等待正文、可见图片与字体，输出 960 × 600 的 JPEG。不会滚动网页或点击弹窗；登录页、Cookie 提示或反爬页可能出现在截图中。
- 两份图片分别保存。展示优先使用用户选定的来源，缺失时用另一份，再缺失时显示原有五色系统的抽象封面。
- 图片工作与生成介绍完全分离。打开新旧合辑详情时，进入视口附近的卡片按需补图；不重新调用模型、翻译内容或改动标题。每次最多处理两个网页；每个已打开的目标总采集预算 25 秒，浏览器启动另有 15 秒上限。失败或只取得一种图片，六小时后再次打开可重试。

## 插件路径

`src/extension/page-images.ts` 通过 `chrome.debugger` 调用 CDP，在新建且静音的后台标签页中渲染并截取页面，随后关闭。只操作自己创建的目标，不接管已打开的用户标签页，不切换前台页。

`debugger` 是 Chrome 不支持声明为 optional 的权限，因此需要加入 manifest；重载或升级时浏览器可能要求重新启用插件。截图时也可能出现浏览器的原生调试提示。这些提示不能由应用隐藏。

临时标签页属于当前浏览器配置，网页会正常执行脚本，可能呈现已有登录态下的内容。截图仅在本地保存，不发给模型或截图服务；导出会将所选的已缓存封面一起嵌入。预览图下载通过 CDP 指定 `includeCredentials: false`。静态文本提取仍不携带登录凭据，两条路径的内容可能不同。

IndexedDB 从版本 1 升级到版本 2，保留 `books` / `jobs`，新增 `images` 存储。合辑只保存图片 ID，图片单独读取，避免 500 个网页的图片反复通过消息和列表接口传输。图片回写与 flags 使用同一事务范围；删除合辑同步清理图片，迟到回写不复活合辑。

## 网页开发路径

先安装截图运行时：

```bash
pnpm exec playwright install chromium
pnpm dev
```

本地服务使用 Playwright 的独立无登录态 Chromium，不连接用户浏览器。资源请求统一转发给现有公开地址校验和 DNS 绑定的网络层，逐次校验跳转；屏蔽非读取请求、WebSocket、Service Worker、弹窗与下载。请求数量、响应体和总体流量均有限额。图片经 Sharp 压缩，写入 `.data/images/`，文件权限为 `0600`。不安装 Chromium 时，新生成合辑仍可尝试静态提取时记录的预览图候选。

## 设计与导出

照片墙使用不等高的圆角图片卡片；列表使用左图右文，在窄窗口中缩小缩略图但保留完整介绍。图片淡入、轻微缩放、卡片抬升和掠过的反光均支持减少动态效果设置。

HTML 导出使用当前界面语言、布局和图片偏好，只嵌入已经缓存的封面，不启动整本合辑的额外抓取。样式、字体和图片离线可用，原网页链接仍需联网。图片缺失不会影响阅读或导出。

参考：[Chrome debugger](https://developer.chrome.com/docs/extensions/reference/api/debugger)、[可选权限限制](https://developer.chrome.com/docs/extensions/reference/api/permissions)、[Playwright Chromium](https://playwright.dev/docs/browsers)。
