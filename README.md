# Tabbit 合辑

将收藏夹整理为一本合辑。每个网页展示预览图或首屏截图，并附按网页类型生成的 AI 介绍与访问链接。详情支持照片墙和列表布局，保留开书动效与固定标题，支持导出含图片的独立 HTML。

## 安装浏览器插件

支持 Chrome / Edge 120 及以上版本。插件可独立使用，不需要 Node.js、本地服务或 `.env`。

1. 解压 `dist/tabbit-collections-extension.zip`，或直接使用项目中的 `dist/extension`。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 点击 Tabbit 合辑插件图标，进入首页。
5. 点击齿轮「设置」，填写 API Key，测试连接并保存。默认使用 DeepSeek 的 `deepseek-flash`；可展开「API 地址与模型」配置支持 Chat Completions JSON 输出的兼容服务。基础地址不要附加 `/chat/completions`。

构建命令：

```bash
pnpm install
pnpm build
```

构建同时生成扩展目录与 ZIP；安装包不包含开发者的 API Key、`.env` 或已有私人合辑。更新已加载的扩展时，在扩展管理页点击重新加载即可。

## 使用

1. 在首页点击「添加」，插件通过浏览器的 `chrome.bookmarks.getTree()` 直接显示收藏夹与书签，无需上传文件。
2. 勾选一个收藏夹作为合辑根目录，其中的网页与子文件夹会整体收录为树状合辑；单个网页仅展示、不可单独勾选。支持搜索与重复链接去重。
3. 设置合辑名称、封面颜色和可选的编辑方向。选择文件夹时带入名称，留空则由 AI 拟定。
4. 点击「生成介绍」。浏览器按需请求读取所选网站的权限，仅将所选内容发送给配置的 API 服务。
5. 确认或修改网页标题、介绍与排列顺序，点击「保存合辑」，合辑会出现在首页。
6. 点击合辑封面开始阅读，也可以导出 HTML。文件内嵌样式、禁止脚本与外部资源，可离线阅读介绍；访问原网页仍需联网。

在「设置 → 网页封面」选择预览图或首屏截图，两份图片会独立保留。新旧合辑在打开详情时按需补图；右上角可以切换照片墙与列表布局。图片只在本地缓存，不额外调用 AI。导出包含当前布局与已缓存的图片，具体获取方案见 [网页封面与详情布局](docs/page-covers.md)。

扩展管理页的「扩展程序选项」也能进入设置。密钥输入框不回填明文；留空保存会保留已有密钥，更换 API 服务域名时需重新填写密钥。可以随时删除保存的密钥。

## 中文与英文

在「设置 → 界面语言」中选择简体中文或 English，立即生效并记住选择，无需保存 API 设置。首次使用时跟随浏览器语言：中文使用简体中文，其余语言使用英文。

首页、创建与确认流程、精选申请、勋章、错误提示、进度和 HTML 导出均有中英文文案。日期和数量按界面语言格式化。已保存的合辑标题、介绍及用户书签内容不会因切换界面语言自动翻译。

新生成任务使用启动时的界面语言，分类主体、网页介绍和自动命名保持一致；任务途中切换界面只影响操作文案。精选申请中的 AI 简介使用点击生成时的界面语言。所有模型提示词统一用英文编写，并明确要求按用户的界面语言输出。

文案集中在 `shared/locales.ts`，后续新增文案必须同时提供两种语言。开发规则见 [AGENTS.md](AGENTS.md)，数据流和兼容说明见 [国际化方案](docs/internationalization.md)。

## 本地保存与后台任务

- 密钥与 API 配置保存于 `chrome.storage.local`，限制为扩展可信上下文访问，不使用浏览器云同步。
- 合辑与生成进度存于扩展自身的 IndexedDB，与普通网页预览的数据独立。
- 生成通过扩展的 offscreen 页面读取 HTML、提取正文并调用模型。关闭首页后保持浏览器运行，任务可继续；返回「添加」即可恢复待确认草稿。
- 浏览器重启中断的任务会显示失败，并保留所选书签供重试；已保存合辑不受影响。
- 保存合辑与完成任务在同一数据库事务中提交，避免重复点击产生重复合辑。
- 卸载扩展会移除其本地数据；需要保留的合辑请先导出 HTML。

## 权限与边界

- `bookmarks`：读取收藏夹树。代码不会修改、移动或删除原始书签。
- `storage`：保存用户的 API 配置。
- `offscreen`：后台解析网页 HTML 和完成整理。
- `debugger`：只为插件自行创建的静音后台页面生成封面截图，完成后关闭；不会截取当前用户页面。新版可能需要在扩展管理页确认新增权限。
- 默认允许请求 `https://api.deepseek.com`；其他 API 地址与所选网页网站在用户操作时按需请求访问权限。
- 静态文本提取不携带登录凭据、不执行网页脚本。封面截图使用真实渲染，页面会执行脚本；插件临时页可能呈现当前浏览器的登录态，截图只保存在本地，导出时会嵌入选中的缓存封面。不会主动点击网页或绕过访问限制。
- 不能可靠读取登录后、付费或主要由脚本渲染的正文；暂不解析 PDF、视频。读取失败仍保留所选书签，并标示介绍仅依据标题或简介推测；视频和音频页面只能依据已取得的页面文字介绍，不处理媒体本体。
- 每本合辑最多 500 个不同链接，同时最多两个生成任务。每页最多采集 14,000 个文本字符，每批最多五个网页，先识别类型与主体，再按类型生成短介绍。
- 普通网页不能读取浏览器书签，必须从安装后的插件进入。参见 [Chrome Bookmarks API](https://developer.chrome.com/docs/extensions/reference/api/bookmarks) 与 [扩展网站权限](https://developer.chrome.com/docs/extensions/reference/api/permissions)。

三个内置合辑为原创排版示例。选择「示例素材」会真实分析 Kaiyi's Notes 的三篇公开文章，正常计入 API 用量。

## 网页识别与 AI 介绍

收藏夹可以混合收录工具、文档、代码仓库、视频、音频、课程、商品、讨论、资源目录、网站主页、资料页、活动和文章。生成过程先识别每个网页的主体与类型，再使用相应的写作要求生成介绍。编辑方向会参与单个网页介绍及自动命名；已填写的合辑名称保持原样。

模型分类包含类型、主体、置信度和信息依据，并随合辑保存。资料不足时保守处理，不因“已读取”就断言取得完整目标内容。旧合辑可继续显示和编辑，不会因升级自动重新生成或产生 API 用量。

普通生成每五个网页由一次调用变为两次（分类、介绍各一次）；未填写合辑名称时另有一次命名调用。精选申请的整体简介仍按需单独生成。分类阶段只使用最多 3,000 个文本字符以及有界元信息，介绍阶段使用最多 14,000 个文本字符。耗时和用量会增加，实际幅度取决于输入和模型响应。

提示词集中于 `shared/prompts.ts`，产品和技术方案详见 [网页分类与介绍方案](docs/webpage-analysis.md)。AI 分析仍只使用提取到的文本与元信息；图片封面是独立的本地采集流程，不增加模型调用。

## 网页开发预览

```bash
pnpm exec playwright install chromium # 网页版首屏截图运行时；浏览器插件不需要
pnpm dev
```

打开 `http://127.0.0.1:5173`，预览后端监听 `127.0.0.1:8787`。普通网页预览可使用粘贴链接与示例素材，也提供设置与插件下载入口。

网页模式优先使用 `.data/api-settings.json` 中保存的配置；尚未保存时兼容项目 `.env`：

```dotenv
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
PORT=8787
```

网页模式的合辑、任务和封面缓存保存在 `.data/books/`、`.data/jobs/`、`.data/images/`；API 配置和图片文件权限为 `0600`。这些开发数据不会装入扩展。构建后可通过 `pnpm start` 在 `http://127.0.0.1:8787` 使用网页版本。

## 项目命名

中文产品名为 **Tabbit 合辑**，英文为 **Tabbit Collections**，项目标识与包名为 `tabbit-collections`。`shared/branding.ts` 提供品牌访问函数与安装包文件名，品牌文案和其他中英文产品文案集中在 `shared/locales.ts`；开发约定见 [AGENTS.md](AGENTS.md)。

产品改名后继续读取原有合辑、草稿和设置，无需重新导入。`src/lib/storage-keys.ts` 中的历史存储标识，以及现有 `books` 数据结构与接口路径，为兼容已有数据而保留，不用于界面展示。

## 实现与验证

```text
src/extension/       插件配置、消息、IndexedDB、后台任务与网页提取
src/components/      首页、收藏选择、API 设置与合辑阅读器
shared/              网页与插件共用的模型调用、分析流程与校验
server/              普通网页开发预览的本机 API
scripts/             扩展构建、打包与真实 API 冒烟测试
tests/               密钥处理、来源校验、生成取消、持久化与安全渲染
```

```bash
pnpm typecheck
pnpm test
pnpm build
```

以下可选测试使用开发环境的密钥并消耗少量真实 API 用量：

```bash
pnpm smoke             # 测试本地服务，保存一本合辑
pnpm smoke:extension   # 独立测试扩展任务引擎，无需启动本地服务
```

扩展引擎测试在 Node 中用 DOM 与 IndexedDB 测试实现验证业务流程；浏览器网页测试验证选择、设置和阅读界面。Chrome 原生安装、权限弹窗、service worker 与 offscreen 的协作还需要加载扩展进行验证。

## 字体

界面使用随扩展打包的 IBM Plex Sans、IBM Plex Sans SC，以及用于等宽文字的 IBM Plex Mono，包含 Regular 和 Medium 字重。字体来源与 OFL 授权位于 `public/fonts/`。导出的独立 HTML 会内嵌字体与授权，离线也能保持排版；完整中英文字库会使每份导出文件增加约 11 MB。
